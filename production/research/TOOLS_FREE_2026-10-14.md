# Guildborne free production tools and motion research

Reviewed 2026-10-14. Research only; no tools or skill packs downloaded, installed, run or published. Free repository code does not make a model subscription, cloud render or external generation API free. Exact eight README/licence routes were reviewed; named extensions have mixed evidence levels. Full dependency/telemetry audits remain pending.
