## ชุดหน้าตา Guildborne ที่เสนอ

1. ปรับกรอบ/ปุ่ม/icon เป็น navy–obsidian, brass/gold, ivory, burgundy และ cyan พอเป็นจุดเน้น สร้างลาย crest และ class symbols ของเกมเอง
2. inventory/craft: slot frames, ingredient states, comparison cards และ item preview ใช้ไอเทมจริงกับ selection player/hero เดิม
3. skills/status: branch/node frames พร้อมแยก learned/equipped/AI-enabled และ preview/apply; เคารพ class gates เดิม
4. quest journal/dialogue: ขอบหนังสือ/tab/portrait กับ track/accept/claim เดิม; ข้อความยังเป็น TextLabel TH–EN
5. combat: portrait frames สำหรับผู้เล่นและฮีโร่สูงสุด5คน, health/cooldown presentation จากข้อมูลจริง และ reduced motion
6. settings: slider ที่ bind volume เดิม แล้วทดลอง scale/accessibility เป็นงานแยก; mobile-controls เป็นภาพประกอบ ไม่แทน controller
7. notification/minimap: สร้าง adapter/queue/lifecycle แล้วตรวจ on-screen clutter และต้นทุนบนมือถือ

ทั้งหมดเป็นแผนดัดแปลง ไม่ใช่ implementation ข้อความ dynamic เช่นราคา ชื่อ สถานะ และบทสนทนาไม่ bake ลงภาพ

## สถานะการส่งต่อ

ตรวจหน้ารายการสด 11 รายการ + primary author/upstream sources + จุดต่อ source แล้ว
ยังไม่มี download/acquisition/import/upload/install/execute, ไม่เปลี่ยน runtime source หรือ registry, runtime IDs และ pinned dependency versions เป็น null
ไม่ได้รัน baseline game tests, Studio/device/cross-server tests หรือขอ human art/UAT/release signoff ในรอบ research นี้

ผู้รับช่วงถัดไป: UI/native UX + asset curator เลือกภาพและตรวจ payload/rights ก่อนทำ prototype adapter แล้วจึงทดสอบ Studio, touch/controller/Thai/reduced motion และ human art review
JSON คู่รายงานเก็บสถานะความไม่แน่นอนและผล independent document review แยกจาก runtime acceptance

Independent document review: **PASS** โดย asset_fit — ตรวจจำนวน/ความซ้ำ, source-fit, license และสถานะหลักฐาน ไม่มี correction; ผลนี้รับรองเฉพาะเอกสาร research ไม่ใช่ payload safety หรือ Studio/device acceptance

Local catalog consistency check: **PASS** — JSON อ่านได้ จำนวน/unique IDs ตรงกัน source paths มีจริง และ acquisition/runtime flags ไม่ถูกยกระดับ
