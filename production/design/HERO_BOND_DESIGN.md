# Hero identity and bond
Status: REQUIRED BEFORE FIRST PUBLIC under GL-2.0 P5; schema, story IDs and proposed three-story minimum remain design decisions, not implemented acceptance.

Use owned hero instance IDs, never display names or class as identity. Explore personality/dialogue preferences, optional personal stories and cosmetic team memories. Do not silently reclassify canonical Rowan: the current founding story uses Warrior; the proposal's Knight example is illustrative.

Begin with one optional story keyed to a specific hero instance and committed participation evidence. Bond should not create compulsory power grind, daily-loss penalties or paid progression bypass. Prefer dialogue/cosmetic recognition first; any combat synergy requires its own balance contract.

Before implementation define bounded schema version, migration/defaults, activity credit/replay rules, duplicate-name behavior, equipment transfers and removal/recovery. Preserve class/XP/Hall and hero reward receipts. Acceptance: same-name heroes remain distinct, repeated claims do not duplicate unlocks, TH/EN story comprehension, real actor animation/fit and user art approval. No existing hero is renamed or reset by this document.
