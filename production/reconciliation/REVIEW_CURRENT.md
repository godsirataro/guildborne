# Registry reconciliation review scope

Reconcile existing canonical inventory before regional production. Preserve current
502asset/73screen rows and89planned character entries, actual statuses, native
bindings and nullable runtime IDs. The checks derive counts from source rather
than overwriting files to match historical numbers.

check_current_registry.py executes four independent modes: full row/routing
coverage, existing reference hashes, actual generator execution with byte-for-byte
status/binding preservation, and validated existing character aliases/presets.
Raw recorded commands and composed packet remain local evidence until a different
reviewer inspects them. File hashes do not establish license, visual quality,
import, physical fit, runtime acceptance or human approval.

The four existing HEAD aliases retain CHR_HEAD canonical identities. Human/Elf/
Orc/Dwarf cosmetics and Wizard appearance remain separate from legacy combat
ancestry. No registry status, game code, model, import ID or production state is
changed by this task. Missing future art and all-game gates remain open.
