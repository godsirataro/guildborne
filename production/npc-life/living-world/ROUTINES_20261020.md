# Stationary work and attention cycles — 2026-10-20

Existing source sets Lighting.ClockTime to 10.5. Previously every registered
actor therefore remained in the shared Work phase throughout a normal session.
The existing animator now passes its existing server timestamp as the optional
sixth argument to NpcLifeSchedule.sample. Day phase and interaction deadlines
retain their existing owners; no world clock, server service or timer is added.

All sixteen existing identities have short work bouts (16–32 seconds), eight
seconds of attentive idle, and staggered offsets. The existing Work/Social
activity output drives existing blend weights, not a new pose writer. This
provides visible work/pause alternation for the six civic envoys and six hosts
that reuse those work poses. The four older Orc residents currently lack matching
CivicWorkMotion poses: their metadata changes, but this patch does not invent
four new occupation animations or claim visible tool use for them.

Borin and the Deepforge host retain the Borin adapter as sole pose owner.
Its existing fade/recovery, contact suppression, dialogue attention and distance
cull remain responsible for their presentation. Generic actors also retain the
existing fade, greeting and dialogue logic. Off-duty daily phases still win;
routine cycles only subdivide Work. Calls without the sixth argument preserve
the previous schedule behavior. Optional missing routine definitions preserve
legacy configurations; malformed or partial supplied definitions fail closed.

No roots move. Quest hooks, dialogue aliases, prompt stations, saves, services,
reward authority and progression are unchanged. Far actors stay accessible;
distance still reduces optional presentation work. This is not walking,
population expansion, a day/night simulation or human art acceptance.
