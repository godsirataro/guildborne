# Character acceptance checklist

- [ ] Genuine Human Standard/Heavy imported bodies: 15 distinct MeshParts, valid R15 joints, caps, skin seams and modesty.
- [ ] At least three palettes visually verified under daylight/night lighting; eyes/clothes unaffected.
- [ ] Flexible tunic/trousers/outer garment have corresponding cages and bend without major clipping on each accepted preset.
- [ ] Rigid hair/headwear/weapon attachments remain stable through idle/walk/run/jump/dodge/basic/skill/emote/downed/recover.
- [ ] Apply changes only owned actor appearance; cancel/preview never commits; stale revision and forged IDs rejected.
- [ ] Existing hero identity/level/class/equipment, five-follower route and legacy ancestry remain intact.
- [ ] Shared Human world NPC adapter preserves existing roots/joints, profession tools, labels/tags, dialogue/quest transactions, talk/work interruption and streaming/respawn cleanup before other races migrate.
- [ ] Genuine persistent reconnect/respawn reproduces appearance and earned progress in an approved isolated namespace.
- [ ] Desktop and simulated mobile portrait/landscape native TH/EN UI, orbit/zoom, unsaved warnings and cleanup.
- [ ] Two/four real clients isolate previews/ownership; busy four-player/twenty-companion performance measured.
- [ ] Physical touch/performance and human artistic/UAT approval.

Unchecked items are pending; source tests, Blender export, Studio placeholders and
historical game evidence do not substitute for these observations. Public/private
publishing, Roblox spending and live commerce are outside this implementation.
