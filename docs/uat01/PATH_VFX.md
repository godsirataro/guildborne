# Advanced art presentation

The existing 24 advanced arts now resolve their own original geometry choreography through `PathVFX` and `PathSkillEffects`. Thirteen patterns distinguish whirlwind, thrust, bastion, dawn, arrow rain, sight, orbit, rune, sanctuary, fate, banner, harmony and eclipse. Tier 3 adds a ground accent. This implements presentation for the existing class paths, not the proposed 35-class migration.

CombatService publishes ActionAbilityId only after an authorized cast; basic attacks clear it. Resolution also checks class and effect, so stale or unknown IDs use the existing fallback. No damage, range, cooldown, unlock or reward changes. The existing global-per-controller geometry caps, distance culling, cast throttling and reserved primary/telegraph budgets apply. Low quality uses existing compact class/effect cues with the path color; it intentionally does not reproduce the full choreography.

Native synthetic acceptance: 24 High and 24 Low cases, noncollidable/nonqueryable/nontouchable geometry, bounded parts, timed cleanup and no delayed geometry after caster removal. Current Studio reported High peaks of 10–30 detail parts; Low used 2–3 primary parts and no detail. These are geometry counts, not physical-device FPS results. The previous lifecycle probe still passes missing/expired/cancelled telegraphs, caster removal and impact cleanup. Server fixture verifies three learned slots, cooldown/locked/safe-zone rejection, exact cleave/master IDs and basic clearing. Its isolated configuration merges the same Expansion abilities as Bootstrap because MCP has a separate module cache.

Evidence: validation-path-vfx-high.json, validation-path-vfx-low.json and validation-path-vfx-server.json. An initial world-camera screenshot was displaced by the active title camera. The replacement `review/path_vfx_gallery.luau` samples real geometry into six frozen ViewportFrames at 0.18 seconds. The resulting [contact sheet](path-vfx-gallery.png) was visually reviewed: distinct whirlwind, arrow rain, layered shields, orbit, healing crosses and fate glyphs, with target silhouettes retained. Full motion, full-party readability, physical devices, human approval and final polish remain pending. No imported animations, external images or cloud asset IDs were created by this change.
