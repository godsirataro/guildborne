# เกาะกิลด์และธีมก่อสร้าง — ขอบเขตเปิดตัวครั้งแรก

วันที่ตัดสินใจ: 2026-10-02 ผู้ใช้ยืนยันให้นำระบบเหล่านี้เข้าแผนและปล่อยพร้อมเกมครั้งแรก ไม่เลื่อนไปเป็นอัปเดตหลังเปิดตัว สถานะ: ขอบเขตที่อนุมัติแล้ว ยังไม่ได้ยืนยันว่า implementation เสร็จ การอัปเดตครั้งนี้แก้เอกสารเท่านั้น; งานพัฒนายังคงพักตามขอบเขตโควต้า15%

## ประสบการณ์หลักที่ต้องมีพร้อมเปิดตัว

ทุกเมืองที่เปิดให้เล่นมีประตู Guild Portal ซึ่งเชื่อมไปยังเกาะ Personal Guild เดียวของผู้เล่น เลือกกลับเกาะตนเอง เยี่ยมเพื่อน ค้นหาด้วยชื่อ/รหัส หรือเลือกเกาะที่เจ้าของเปิดสาธารณะได้ ไม่ต้องซื้อฐานแยกตามเมือง Personal Guild ยังแยกจากองค์กร Player Guild ของผู้เล่นหลายคน

ผู้เล่นได้รับที่ดินเริ่มต้นและ Guild Hall ผ่านเควสต์ฟรี เขตขยายใช้ระบบปลดเงื่อนไขก่อนซื้อด้วย Robux ตามคำชี้แจงล่าสุดของผู้ใช้: ทำเควสต์ประจำเขตและผ่านข้อกำหนดก่อนจึงเปิดสิทธิ์ซื้อ พร้อมรวบรวมและส่งมอบวัสดุที่เขตกำหนด Robux ไม่สามารถข้ามเควสต์หรือทดแทนวัสดุได้ ต้องเห็นขอบเขต ราคา เงื่อนไข และพื้นที่ที่ได้ก่อนยืนยัน แต่ละแปลงที่เปิดสำเร็จมีสิทธิ์เป็นเจ้าของถาวรในข้อมูลบันทึก ไม่ใช่สินค้าที่ซื้อขยายได้ไม่จำกัดทันที

เลือกวางและย้าย Hall อาคาร และของตกแต่งได้เองภายในเขตที่ปลดล็อก หมุนได้ มีตัวช่วยตารางและปรับละเอียด แสดงเงาตัวอย่างกับสาเหตุที่วางไม่ได้ ไม่ทับอาคาร ไม่ออกนอกเขต และต้องรักษาทางจากจุดวาร์ปไปยังอาคารสำคัญ มีแบบฐานสำเร็จรูปให้วางและปรับต่อได้ รองรับการกดวางบนมือถือและคีย์บอร์ด/คอนโทรลเลอร์ ไม่บังคับลากอย่างเดียว

ธีมเป็นชุดอาคารหรือรูปลักษณ์ หลังคา กำแพง ถนน สวน และเฟอร์นิเจอร์ ผู้เล่นผสมธีมบนเกาะเดียวและเลือกใช้รายอาคารได้ การซื้อธีมไม่รื้อฐานเดิมหรือรีเซ็ตระดับอาคาร รื้อของตกแต่งแล้วคืนคลัง; ย้ายของไม่ทำให้สิทธิ์ที่ซื้อสูญหาย แยกสิทธิ์ที่ดิน สิทธิ์อาคาร และสิทธิ์ธีมออกจากกัน

## ธีมและรายได้

ทิศทางชุดธีม: มนุษย์ เอลฟ์ คนแคระ ออร์ค นักเวท และเมืองรวม จำนวนชุด/ชิ้นที่จะผลิตและราคาเปิดตัวยังต้องกำหนด ไม่ถือว่าทั้งหกเมืองหรือทุกธีมสร้างเสร็จจากการยืนยันระบบครั้งนี้

เปิดตัวพร้อมระบบซื้อธีมถาวรด้วย Robux และแบบตกแต่งที่หาได้จากเควสต์/ชื่อเสียง เช่น โรงตีเหล็กคนแคระ สวนเอลฟ์ และครัวงานเลี้ยงออร์ค ผู้ใช้ยืนยันให้เขตขยายเป็นสินค้าซื้อด้วย Robux หลังผ่านเควสต์และเงื่อนไขวัสดุ ข้อนี้แทนข้อเสนอเดิมที่ให้แปลงหลักซื้อด้วย Gold/วัสดุอย่างเดียว เกาะเริ่มต้นฟรียังคงอยู่ ผลของเขตซื้อที่มีต่ออาคารผลิต จำนวนฮีโร่ และความก้าวหน้าต้องออกแบบสมดุลและเปิดเผยก่อนขาย; ยังไม่สรุปว่าพื้นที่แบบเสียเงินจะเป็นข้อบังคับต่อเนื้อเรื่องหลัก ไม่มีการสุ่มธีมเสียเงินในขอบเขตนี้

Pass เหมาะกับชุดสิทธิ์ถาวรซื้อครั้งเดียว; Developer Product ใช้เมื่อมีสินค้าที่ซื้อซ้ำได้จริง ต้องกำหนดสินค้า ราคา และ receipt/entitlement contract ก่อนเปิดขาย ไม่ใส่ ID สมมติ ไม่เปิดยอดขายด้วยการแก้เอกสารนี้ การซื้อซ้ำ/rejoin/retry ต้องไม่หักหรือให้สิทธิ์ซ้ำ และแสดงผลซื้อสำเร็จเมื่อเซิร์ฟเวอร์ยืนยันเท่านั้น

## การเยี่ยมชมและสิทธิ์

เจ้าของเลือกส่วนตัว/เพื่อน/สาธารณะได้ ผู้เยี่ยมชมไม่มีสิทธิ์ย้าย รื้อ หยิบทรัพยากร หรือใช้คลังเจ้าของโดยปริยาย ช่วงเปิดตัวเสนอให้เจ้าของเป็นผู้สร้างคนเดียวและเยี่ยมเฉพาะเกาะที่เจ้าของออนไลน์ก่อน รายชื่อเกาะต้องแสดงสถานะ พร้อมจัดการเจ้าของออก เปลี่ยนสิทธิ์ เตะผู้เยี่ยมชม และกลับเมืองเดิมอย่างปลอดภัย

หน้าค้นพบมีเพื่อน ค้นหาชื่อ/รหัส เปิดใหม่ และสุ่มแนะนำ ข้อความชื่อ/คำอธิบายต้องกรองตามแพลตฟอร์ม จำกัดผู้เยี่ยมชมและชิ้นตกแต่งตามผลทดสอบอุปกรณ์จริง ไม่ขายความจุเกินที่รองรับ

ถนนมิติกิลด์ที่มี6–8ประตูเป็นแนวทางเสริม ไม่จำเป็นต้องเรียงเกาะของผู้เล่นทุกคนทั่วเกม และยังไม่กำหนดเป็นเงื่อนไขเปิดตัว การร่วมสร้างหลายเจ้าของและการเข้าชมเกาะออฟไลน์ยังแยกไว้พิจารณา ไม่ลดทอนระบบวาร์ป/เยี่ยมเกาะหลักที่ต้องเปิดตัวพร้อมกัน

## ลำดับงานภายใน — เปิดใช้งานพร้อมกันเมื่อครบ

1. Schema แปลง/อาคาร/สิทธิ์ธีม การย้ายข้อมูลเก่าโดยไม่เสียสิทธิ์ และ server validation
2. เควสต์รับเกาะ เงื่อนไขเปิดซื้อเขต Robux การส่งวัสดุ และตัวแก้ไขฐานพร้อมย้าย/หมุน/คืนคลัง/แบบสำเร็จรูป
3. โหลดเกาะ วาร์ปจากทุกเมือง รายชื่อเกาะ สิทธิ์เข้าชม และการกลับเมือง
4. คลังธีม พรีวิว ผสมธีม ซื้อและคืนสิทธิ์เมื่อกลับเข้าเกม รวมระบบสินค้า Robux
5. ทดสอบครบวงจรบนมือถือ/PC/คอนโทรลเลอร์ หลายผู้เล่น เซฟและข้อผิดพลาด ก่อนเปิดระบบทั้งหมดพร้อมเกม

ลำดับข้างต้นเป็นการแบ่งพัฒนาและทดสอบภายใน ไม่ใช่การเลื่อนส่งระบบซื้อธีมหรือเยี่ยมชมออกจากเกมเปิดตัว

## เกณฑ์ก่อนประกาศพร้อมเปิดตัว

- ผู้เล่นใหม่รับเกาะฟรี ขยายแปลง ย้าย Hall ตกแต่ง ผสมธีม ออกจากเกมและกลับมาแล้วข้อมูลถูกต้อง
- วางซ้อน นอกเขต ปิดทางวาร์ป และคำสั่งจากผู้ไม่มีสิทธิ์ถูกปฏิเสธโดยเซิร์ฟเวอร์
- ย้าย/รื้อ/เปลี่ยนธีมไม่ลบระดับอาคาร งานผลิต สิทธิ์ หรือของในคลัง; กำหนดนโยบายอาคารมีงานค้างอย่างชัดเจน
- ทุกเมืองที่เปิดตัววาร์ปไปเกาะเดียวกันและกลับได้; เพื่อนเยี่ยมได้ตามสิทธิ์ เจ้าของออกหรือปิดเกาะแล้วไม่มีผู้เล่นติดค้าง
- ธีมที่ซื้อคงอยู่เมื่อ rejoin; ทดสอบยกเลิกซื้อ receipt ซ้ำ ความล่าช้า และเซิร์ฟเวอร์ขาดการเชื่อมต่อ
- จำนวนชิ้น/ผู้เยี่ยมชมผ่านเกณฑ์ FPS หน่วยความจำ และเวลาโหลดบนอุปกรณ์ที่ระบุ พร้อม human UAT

อ้างอิงสถานะ implementation จริงจาก [รายการงาน](uat01/WORK_CHECKLIST.md) และ [handoff](uat01/HANDOFF.md) ขอบเขตเปิดตัวที่เพิ่มนี้ทำให้ประมาณการความคืบหน้า40%ที่เคยตอบในแชตไม่ใช่ค่าที่ใช้ติดตามต่อได้ ต้องประเมินงานใหม่ก่อนให้เปอร์เซ็นต์

## คำชี้แจงล่าสุด: การปลดเขตที่ซื้อด้วย Robux

ยืนยันโดยผู้ใช้2026-10-02: ไม่เปิดให้ซื้อทุกเขตได้ตลอด ต้องผ่านเควสต์ของเขตก่อนถึงจะมีสิทธิ์ซื้อ และต้องหาของมาใส่ด้วย

ลำดับที่เสนอให้ใช้: ล็อกเขต → ผ่านเควสต์ → เปิดสิทธิ์ซื้อ → ซื้อ Robux สำเร็จและบันทึกสิทธิ์ → ส่งวัสดุครบ → เปิดพื้นที่ก่อสร้าง ผู้ใช้ยืนยันว่าต้องมีทั้งเควสต์ การซื้อ และวัสดุ แต่ลำดับส่งวัสดุก่อน/หลังซื้อยังเป็นรายละเอียดที่เสนอ ไม่ใช่ข้อยืนยันจากผู้ใช้ ต้องแสดงรายการวัสดุทั้งหมดก่อนเปิดหน้าซื้อเสมอ

แยกสถานะ QuestUnlocked, PurchaseEntitled, MaterialsDelivered และ Buildable ออกจากกัน ผู้ที่ซื้อแล้วแต่ส่งของไม่ครบต้องกลับมาทำต่อได้ ไม่เสนอให้ซื้อเขตเดิมซ้ำ ไม่สูญสิทธิ์เมื่อออกเกม วัสดุที่ส่งแล้วต้องบันทึกและห้ามหักซ้ำ ระบบตรวจเงื่อนไขบนเซิร์ฟเวอร์ก่อนเสนอซื้อ และเมื่อรับ receipt สำเร็จต้องรักษาสิทธิ์ที่จ่ายแล้วไว้แม้สถานะเควสต์หรือเนื้อหาเปลี่ยน โดยพักการเปิดใช้หรือกู้คืนอย่างชัดเจนแทนการลบสิทธิ์

เพิ่ม acceptance: ผู้ไม่ผ่านเควสต์ซื้อไม่ได้; ผ่านเควสต์แต่ยังไม่ซื้อสร้างไม่ได้; ซื้อแล้ววัสดุไม่ครบเห็นความคืบหน้าและไม่ถูกซื้อซ้ำ; ครบทุกเงื่อนไขเปิดเขตครั้งเดียว; receipt/ส่งวัสดุซ้ำและ reconnect ไม่เพิ่มสิทธิ์หรือหักของซ้ำ ราคา เควสต์ และรายการวัสดุรายเขตยังไม่ได้กำหนด
