## หลักฐาน

- `ACQUISITION_MANIFEST.json`: ผลครบ 94 รายการ พร้อมพาธและ SHA256
- `quaternius-archive-validation.json`: ผลตรวจ ZIP 9 ไฟล์ที่ผู้ใช้ส่งมา (8 แพ็ก) และรายละเอียดรายการภายใน
- `receipts.json`: หลักฐานข้อความยืนยัน Roblox Inventory
- `archive-validation.json`: ผลตรวจ ZIP Kenney 16 ไฟล์
- `kenney-manifest.json`, `cinderlore-manifest.json`, `external-agent/manifest.json`: ที่มาและข้อมูล license; manifest ของงานย่อยเก็บสถานะเดิมในเวลานั้น ให้ใช้ ACQUISITION_MANIFEST.json เป็นยอดปัจจุบัน

Cinderlore ใช้ในโปรเจกต์ Roblox ตาม license ที่เก็บไว้ ห้ามแจกไฟล์แอนิเมชันแยกหรือใส่ public asset repository

ไฟล์อยู่ในโฟลเดอร์นี้และ external-agent ไม่มีการเพิ่ม third-party assets ลง Git หรือเผยแพร่เกม
