# Runtime world overviews

Captured in Roblox Studio, Guildborne - Staging, 2026-10-02. These show the actual current native geometry, not image-generated concept art.

- `central-city.png`: service city, district roads, buildings and decorative offshore islands. The offshore scenery is not the three regional encounter maps.
- `personal-guild.png`: existing Hall level2 staging guild, training area, gathering area and Goblin Camp. This is an existing-profile view, not a fresh-player starting state.

Both are 874×402 Studio viewport captures. A temporary local camera controller held the overview; player position and save data were untouched. GUI/camera states were restored and the controller removed before stopping owned Play. No cloud upload. Crop/aspect, compression and in-game thumbnail binding remain pending.

Native sources: `src/server/Services/CentralCityWorld.luau`, `CityWorld.luau`, `WorldService.luau`. Pictures do not certify multiplayer, device acceptance or completion of all game systems.
